# Nifty100 Data Foundation

## Sprint 1 - Data Foundation

### Project Objective

Build an ETL pipeline that loads Nifty100 financial data into a SQLite database, validates it using Data Quality (DQ) rules, and prepares it for analytics.

### Technologies Used

- Python
- Pandas
- SQLite
- SQLAlchemy
- OpenPyXL
- Pytest
